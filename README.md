# ورقة — لوحة الويب العامة

أداة المعلّم للاختبار الورقي. البيانات في `localStorage` تحت `waraqa-v1`.

هذه اللوحة وجه المنتج العام. النواة (نماذج أ/ب، قفل، نسخة JSON، محرك OOXML) في `Waraqa-Code`.

## ماذا نعرض

- للمعلم: تجربة محلية بلا حساب
- للمدارس: حزمة تجريب (هوية + كلمة Word + حدود صادقة) عبر `#/schools`

## قيود

- لا توافق Word كامل
- لا اعتماد وزاري
- لا حسابات طلاب ولا تصحيحًا آليًا
- الرخصة التجارية مسودة؛ MIT للنسخ المنشورة
